Q1 – debugging – runner

سؤال 1 – تصحيح – تشغيل البرنامج

البرنامج الموجود في الملف كُتب لطباعة المخرجات المطلوبة، لكنه فشل: يوجد فيه بعض أخطاء الترجمة وأيضاً خطأ منطقي. صححوا أولاً أخطاء الترجمة حتى يتم ترجمة البرنامج، شغلوه، وإذا لم تكن المخرجات الناتجة هي المخرجات المطلوبة — صححوا أيضاً الأخطاء المنطقية، حتى تحصلوا على النتيجة المطلوبة.

المخرجات المطلوبة:

Java is running
All good

تلميح: افحصوا الكلمات المحجوزة في تعريف الدالة الرئيسية وحروفها الكبيرة/الصغيرة — وأيضاً هل يجب أن تلتصق السطران ببعضهما البعض.

نزّلوا الملف Fix01_Runner.java إلى بيئة العمل، حددوا وصححوا الأخطاء، وشغلوا البرنامج.
عرض هيكل الكود 
/**
 * Exercise 1: Debugging - Runner
 *
 * Fix the program so that it compiles, runs,
 * and prints the output shown below.
 *
 *      Required output:
 *
 *      Java is running
 *      All good
 */
public class Fix01_Runner
{
    public Static void main(String[] args)
    {
        system.out.print("Java is running");
        System.out.println("All good");
    }
}

Q3 – debugging – path

سؤال 3 – تصحيح – مسار ملف

البرنامج الموجود في الملف كُتب من أجل طباعة المخرجات المطلوبة، لكنه فشل: يوجد فيه بعض أخطاء الترجمة وأيضاً خطأ منطقي. صححوا أولاً أخطاء الترجمة حتى يتم تجميع البرنامج، شغلوه، وإذا لم تكن المخرجات الناتجة هي المخرجات المطلوبة — صححوا أيضاً الأخطاء المنطقية، حتى تحصلوا على النتيجة المطلوبة.

عرض هيكل الكود

 * Exercise 3: Debugging - Path

 *
 *      Required output:
 *
 *      Drive:
 *      C:\Users\Dana
 */
public class Fix03_Path
{
    public static void main(String[] args)
    {
        System.out.Println("Drive:")
        System.out.println("C:/Users/Dana");
    }
}
