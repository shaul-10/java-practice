## 4. בניית קובץ JSON — פורמט מורחב

### 4.1 מוסכמת שמות קבצים

```
firstProgramPractice_01.json     ← תוכנית ראשונה, רמה 01, עברית
firstProgramPractice_01_ar.json  ← תוכנית ראשונה, רמה 01, ערבית
arrays1dPractice_01.json         ← מערכים חד ממדיים, רמה 01
```

**תבנית כללית:**
```
[topicKeyword]_[level].json
[topicKeyword]_[level]_ar.json
```

### 4.2 מבנה כללי של הקובץ

```json
{
  "level": "01",
  "topic": "תוכנית ראשונה והדפסות",
  "questionsHe": [ ...שאלות... ]
}
```

### 4.3 שאלת multichoice

```json
{
  "type": "multichoice",
  "topic": "נושא קצר 2–4 מילים",
  "text": "מה יהיה פלט התוכנית הבאה?",
  "code": "public static void main(String [] args) {\n    System.out.print(\"Hello \");\n    System.out.print(\"World\");\n}",
  "options": [
    { "type": "code", "text": "Hello World" },
    { "type": "code", "text": "Hello\nWorld" },
    "אין פלט - התוכנית לא מתקמפלת"
  ],
  "answer": 0,
  "explanation": [
    { "type": "he",   "text": "הסבר בעברית." },
    { "type": "code", "text": "Hello World" }
  ]
}
```

**סוגי אפשרויות בשדה `options`:**

| צורה | מתי להשתמש |
|------|-------------|
| מחרוזת עברית `"אין פלט..."` | תשובה טקסטואלית — מוצגת RTL |
| מחרוזת קוד `"System.out.println(...);"` | שורת קוד יחידה ללא ירידות שורה — מוצגת LTR |
| אובייקט `{ "type": "code", "text": "..." }` | **חובה** כאשר התשובה מכילה `\n` (ירידות שורה) או רווחים משמעותיים בתחילה/סוף |

> **כלל חשוב:** תשובה שמציגה פלט רב-שורתי או פלט עם רווחים — תמיד בפורמט אובייקט code. אחרת ה-`\n` לא יוצג והתשובות ייראו זהות!

### 4.4 שאלת gapselect

קוד עם חורים מסומנים `[[1]]`, `[[2]]`... — לכל חור dropdown משלו.

```json
{
  "type": "gapselect",
  "topic": "print לעומת println",
  "text": "ברצוננו לקבל את הפלט הבא:",
  "output": "1, 2\n3, 4\n5",
  "text2": "השלימו את התוכנית כך שתיצור את הפלט המבוקש:",
  "codeLines": [
    "public static void main(String [] args) {",
    "    System.out.[[1]](\"1, 2\");",
    "    System.out.[[2]](3);",
    "    System.out.println(5);",
    "}"
  ],
  "gaps": [
    { "id": 1, "options": ["println", "print"], "answer": "println" },
    { "id": 2, "options": ["print", "println"], "answer": "print" }
  ],
  "explanation": [
    { "type": "he", "text": "הסבר." },
    { "type": "code", "text": "1, 2\n3, 4\n5" }
  ]
}
```

**שדות:**
- `output` — הפלט הרצוי, מוצג כבלוק LTR עם מסגרת מקווקוות. **אנגלית/מספרים בלבד**
- `text2` — טקסט הנחיה שמוצג **אחרי** בלוק הפלט (אופציונלי)
- `codeLines` — מערך שורות קוד (מחרוזות). כל `[[n]]` מוחלף ב-dropdown
- `gaps` — הגדרת כל חור: `id` תואם למספר בסוגריים, `options` רשימת אפשרויות, `answer` התשובה הנכונה (מחרוזת מדויקת מתוך options)

### 4.5 שאלת cloze

dropdown מוטמע בתוך שורת קוד — כל שורה מוגדרת כאובייקט.

```json
{
  "type": "cloze",
  "topic": "מבנה תוכנית",
  "text": "נתונה המחלקה Hello המדפיסה את הפלט הבא:",
  "output": "Hello\nBye",
  "text2": "השלימו את המחלקה:",
  "codeLines": [
    { "before": "public class ", "blank": { "options": ["Hello", "hello"], "answer": "Hello" }, "after": " {" },
    { "before": "    public static void ", "blank": { "options": ["main", "Main"], "answer": "main" }, "after": "(String[] args) {" },
    { "before": "        System.out.println(\"Hello\");", "blank": null, "after": "" },
    { "before": "    }", "blank": null, "after": "" },
    { "before": "}", "blank": null, "after": "" }
  ],
  "explanation": [
    { "type": "he", "text": "הסבר." }
  ]
}
```

**שדות בכל שורה ב-`codeLines`:**
- `before` — הטקסט שלפני ה-dropdown (כולל אינדנטציה!)
- `blank` — `{ options, answer }` או `null` אם אין dropdown בשורה
- `after` — הטקסט שאחרי ה-dropdown

> **אינדנטציה:** יש לכלול את הרווחים בשדה `before` — 4 רווחים לכל רמת קינון.

### 4.6 כללי ברזל לשדות JSON

| שדה | כלל |
|-----|-----|
| `type` | חובה בכל שאלה: `"multichoice"` / `"gapselect"` / `"cloze"` |
| `answer` (multichoice) | **תמיד `0`** — התשובה הנכונה תמיד ראשונה באפשרויות |
| `answer` (gaps/blank) | מחרוזת מדויקת מתוך `options` |
| `code` | שבירת שורה = `\n`. אם אין קוד — `null` |
| `options` (multichoice) | לפחות 2, רצוי 4. הנכונה **תמיד ראשונה** |
| `explanation` | מערך בלוקים: `"he"` לטקסט, `"code"` לקוד |
| `output` | פלט רצוי — אנגלית/מספרים בלבד, `\n` לירידת שורה |
| כמות שאלות | **10 בדיוק** לכל קובץ |

### 4.7 ערבוב בהרצת השאלון

- **סדר השאלות** — קבוע לפי הסדר ב-JSON (מהקל לקשה)
- **אפשרויות multichoice** — מעורבבות בכל הרצה (התשובה עוקבת אוטומטית)
- **אפשרויות בתוך dropdowns** (gapselect/cloze) — מעורבבות בכל הרצה
- כל dropdown מתחיל ב-`?` — חובה לבחור בכל התיבות לפני "בדוק תשובות"

### 4.8 טיפול בבעיות RTL (כיוון טקסט)

אפשרויות טקסט (עברית/ערבית) שמסתיימות במילה אנגלית גורמות לתצוגה הפוכה. הפתרון: הוסף `\u200f` **לפני** המילה האנגלית.

```json
"options": [
  "מערך של 5 תאים מסוג \u200fboolean",
  "שגיאת קומפילציה"
]
```

**מתי לא צריך:**
- אפשרויות מסוג code (אובייקט או מחרוזת קוד) — מוצגות LTR אוטומטית
- אפשרויות שהן מספרים בלבד — ניטרליות בכיוון
- הטמפלט מזהה אוטומטית עברית **וגם ערבית** כ-RTL

### 4.9 קובץ JSON ערבית

המפתח בקובץ הערבי יכול להיות `questionsAr` או `questionsHe` — הכלי מזהה את השפה לפי בחירת המשתמש בעת ההעלאה, וקורא `questionsAr` או `questionsHe` או `questions`.

**מה מתורגם / לא מתורגם:**

| מתורגם | לא מתורגם |
|---------|-----------|
| `topic` | `type` |
| `text`, `text2` | `output` (פלט קוד) |
| `options` (טקסט בלבד) | `options` מסוג code |
| `explanation type: "he"` | `explanation type: "code"` |
| — | `codeLines` (קוד) |
| — | `gaps` (options + answer הם קוד) |

## 11. הוראות לקלוד בפרויקט חדש

כשמתחילים בניית סט שאלות סגורות לנושא חדש:

### שלב 1 — הצע
הצג טבלה עם 10 שאלות כולל **סוג כל שאלה** (multichoice / gapselect / cloze). חכה לאישור ועריכה. **אל תייצר JSON לפני אישור.**

### שלב 2 — בנה JSON בפורמט המורחב
- שדה `type` בכל שאלה
- `answer: 0` בשאלות multichoice
- אפשרויות רב-שורתיות — פורמט `{type: "code", text}`
- מחרוזות `\n` בשדות קוד, לא שורות אמיתיות
- `code: null` אם אין קוד
- שאלות gapselect: `output` + `text2` + `codeLines` + `gaps`
- שאלות cloze: `codeLines` כאובייקטים עם `before`/`blank`/`after` ואינדנטציה
- הסבר: בלוק `he` + בלוק `code` קצר

### שלב 3 — בדוק בעצמך לפני הצגה
- לא עברית בשדות code / codeLines / output
- לא `// ב-main:` בקוד
- אפשרויות טקסט עם מילים אנגליות — הוסף `\u200f` לפניהן
- `answer` ב-gaps/blank תואם בדיוק לאחת האפשרויות
- מבנה JSON תקין — בדוק עם `json.loads` ב-Python

### שלב 4 — לאחר אישור המשתמש
הנח למשתמש לבצע: תרגום, יצירת HTML.
אלה פעולות שהמשתמש מריץ על המחשב שלו.
**אין ליצור קובץ HTML** — למשתמש יש כלי משלו לכך.
