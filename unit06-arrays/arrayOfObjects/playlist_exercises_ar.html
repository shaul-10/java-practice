التعليمات العامة

في هذا التمرين ستُنفّذون خطوةً بخطوة صنف PlayList.

حرية الاختيار: يمكنكم حلّ البنود بالترتيب الذي يناسبكم — لا يلزم حلّ جميعها ولا الالتزام بالترتيب. يُنصح بالبدء بالبنود 1–3 (البنّاؤون، add، toString) حتى تتمكّنوا من اختبار بقية البنود.

خطوات العمل:

  1. نزّلوا ملفات المشروع الثلاثة وضعوها في نفس المجلد.
    ⬇ Song.java ⬇ PlayList.java ⬇ Main.java

    روابط إضافية للتنزيل متوفّرة أيضًا في أسفل الصفحة.

  2. اقرأوا وصف التابع في البند المعني.
  3. نفّذوا التابع داخل PlayList.java.
  4. شغّلوا دالة الاختبار المناسبة في المختبر.
  5. تأكّدوا من أن جميع الاختبارات تطبع PASS.
يجب أن تكون المصفوفة بدون فجوات في كل مرحلة.

الصنف Song — مُعطى

تمثّل أغنية واحدة في قائمة التشغيل. مُعطاة جاهزة — لا حاجة لتعديلها.

  • title — اسم الأغنية (String)
  • artist — اسم الفنان (String)
  • duration — المدة بالثواني (int)
  • plays — عدد مرات التشغيل (int، يُهيَّأ إلى 0)
ملاحظة: تابع equals يفحص كلًّا من title وartist — تُعدّ الأغنيتان متطابقتين فقط إذا كانا كلاهما متطابقَين.
public class Song {
    private String _title;
    private String _artist;
    private int    _duration;
    private int    _plays;

    public Song(String title, String artist, int duration) {
        _title=title; _artist=artist; _duration=duration; _plays=0;
    }
    public String getTitle()    { return _title;    }
    public String getArtist()   { return _artist;   }
    public int    getDuration() { return _duration; }
    public int    getPlays()    { return _plays;    }
    public void setPlays(int plays) { _plays=plays; }
    public void addPlay()           { _plays++;     }
    public boolean equals(Song other) {
        return _title.equals(other._title) && _artist.equals(other._artist);
    }
    public String toString() {
        return _title+" | "+_artist+" | "+_duration+"s | plays:"+_plays;
    }
}

كيفية تشغيل المختبر

يحتوي ملف المختبر Main.java على 18 دالة اختبار — واحدة لكل بند.

القاعدة الذهبية: شغّلوا فقط البنود التي أنهيتم تنفيذها.
  1. نفّذوا التابع في PlayList.java.
  2. في main — احذفوا // قبل استدعاء البند المعني.
  3. شغّلوا وتأكّدوا من PASS في جميع الاختبارات.
كل دالة اختبار تبني بياناتها من الصفر — لا تبعية بين البنود.

مثال على تشغيل البنود 1 و2 و3 — بقية البنود لا تُختبر لأنها تظهر كتعليق:

public static void main(String[] args) {
    testSection1();
    testSection2();
    testSection3();
    // testSection4();  <-- remove // when ready
    // ...
}
