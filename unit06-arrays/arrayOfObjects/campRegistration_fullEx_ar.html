تمرين: نظام التسجيل في المخيّم

مع اقتراب فصل الصيف، تُعرض مخيّمات كثيرة للطلاب. لإدارة التسجيل بكفاءة، سنبني نظام برمجي يتيح إضافة المشاركين، والبحث عن بياناتهم، وتحديث المعلومات وعرض القائمة. يتكوّن النظام من صنفين: صنف Camper الذي يمثّل مشاركًا واحدًا، وصنف Camp الذي يدير مصفوفة المشاركين ويوفّر جميع العمليات على المخيّم.

في هذا التمرين ستُنفّذون خطوةً بخطوة صنف Camp.

حرية الاختيار: يمكنكم حلّ البنود بالترتيب الذي يناسبكم — لا يلزم حلّ جميعها ولا يلزم الالتزام بالترتيب. يُنصح بالبدء بالبنود 1–3 (البنّاؤون، add، toString) حتى تتمكّنوا من اختبار بقية البنود، ومن هنا يمكنكم الاختيار بحرية.

خطوات العمل:

  1. نزّلوا ملفات المشروع الثلاثة وضعوها في نفس المجلد في بيئة التطوير لديكم.

    روابط إضافية للتنزيل متوفّرة أيضًا في أسفل الصفحة.

  2. اقرأوا وصف التابع في البند المعني.
  3. نفّذوا التابع داخل Camp.java.
  4. شغّلوا الدالة المناسبة في المختبر وفق التعليمات الواردة في البند.
  5. تأكّدوا من أن جميع الاختبارات تطبع PASS.
يجب أن تكون المصفوفة بدون فجوات في كل مرحلة — يجب أن يظهر جميع المشاركين المسجّلين بشكل متتالٍ من بداية المصفوفة.

صنف Camper — مُعطى

يمثّل هذا الصنف مشاركًا واحدًا في المخيّم. يُعطى لكم جاهزًا — لا حاجة لتعديله.

الخصائص:

  • _name — اسم المشارك (String)
  • _id — رقم الهوية (String)
  • _phone — رقم الهاتف (String)
  • _age — العمر (int)
public class Camper {
    private String _name;
    private String _id;
    private String _phone;
    private int    _age;

    public Camper(String id, String name, String phone, int age) {
        _id    = id;
        _name  = name;
        _phone = phone;
        _age   = age;
    }

    public String getName()  { return _name;  }
    public String getId()    { return _id;    }
    public String getPhone() { return _phone; }
    public int    getAge()   { return _age;   }

    public void setPhone(String phone) { _phone = phone; }
    public void setAge(int age)       { _age   = age;   }

    public String toString() {
        return _id + " | " + _name + " | " + _phone + " | age:" + _age;
    }
}

يحتوي ملف المختبر Main.java على دالة main و-18 دالة اختبار — واحدة لكل بند.

خطوات العمل لكل بند:

  1. نفّذوا التابع في Camp.java.

    static void testSection2() {

        Camp c = new Camp(3);
        check("add Ron returns true",    c.add("123456789", "Ron",  "050-1111111", 14));
        check("add Dana returns true",   c.add("204444444", "Dana", "050-2222222", 12));
        check("add Noa returns true",    c.add("111111111", "Noa",  "050-3333333", 13));
        check("dup id returns false",    !c.add("123456789", "Ron2", "050-9999999", 15));
        check("full camp returns false",  !c.add("999999999", "Zoe",  "050-0000000", 11));
        check("size is 3", c.getNumCampers() == 3);

        Camper[] merged2 = Camp.merge(arr1, 3, empty, 0);
        check("merge with empty: length 3", merged2.length == 3);
        check("merge with empty: first Noa", merged2[0].getName().equals("Noa"));
