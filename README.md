## פורמט הקבצים

כל קובץ JSON מכיל 10 שאלות סגורות במבנה הבא:

```json
{
  "level": "01",
  "topic": "שם הנושא",
  "questionsHe": [
    {
      "topic": "נושא השאלה",
      "text": "טקסט השאלה",
      "code": "קוד Java (או null אם אין)",
      "options": ["תשובה נכונה", "תשובה ב", "תשובה ג", "תשובה ד"],
      "answer": 0,
      "explanation": [
        {"type": "he", "text": "הסבר בעברית"},
        {"type": "code", "text": "דוגמת קוד"}
      ]
    }
  ]
}
```

> התשובה הנכונה היא תמיד האפשרות הראשונה (`answer: 0`)
